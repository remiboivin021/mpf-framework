# Safety Reassessment

## Purpose

Define when and how to perform safety reassessment after changes.

## Trigger Conditions

Safety reassessment is required when:
- Safety-critical code is modified
- New hazards are introduced
- Safety requirements change
- Failure modes change
- Operating conditions change

## Reassessment Process

### 1. Review Change
- Identify what changed
- Review change impact analysis
- Identify affected safety functions

### 2. Update Hazard Analysis
- Identify new hazards
- Reassess existing hazards
- Update risk levels

### 3. Verify Safety Requirements
- Confirm requirements still met
- Update requirements if needed
- Verify traceability

### 4. Update Safety Case
- Update safety arguments
- Update evidence
- Document changes

### 5. Approval
- Safety engineer review
- Management approval
- Document approval

## Documentation

All reassessments must be documented with:
- Change description
- Hazard analysis updates
- Safety verification results
- Approval signatures
